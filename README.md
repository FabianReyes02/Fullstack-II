Cómo iniciar el proyecto

En la carpeta del proyecto, se pueden usar los siguientes comandos:

npm start

Inicia la aplicación en modo de desarrollo.
Se puede abrir en el navegador desde http://localhost:3000
.
Cada vez que se hagan cambios en el código, la página se actualizará automáticamente.

npm test

Ejecuta los tests de la aplicación en modo interactivo.
Sirve para comprobar que las funciones principales estén funcionando correctamente.

npm run build

Crea la versión lista para producción dentro de la carpeta build.
Optimiza los archivos para que la app funcione rápido y esté lista para subir a un servidor.
